API docs

Everything the web tool does is available as a plain HTTP API — same rules, same cost estimator, same monthly quota per plan.

Getting started

  1. Sign in with Google or GitHub.
  2. Open the tool, click API keys in the top bar, and generate one. It's shown once — copy it somewhere safe.
  3. Send it as Authorization: Bearer <your key> on any request below.
You don't need an account or a key to try POST /v1/lint at all — it works anonymously too, just without saved history and under the plain per-IP rate limit instead of your plan's monthly quota.

How to use these docs

The sidebar on the left jumps to a section. Each endpoint block shows the HTTP method + path, whether auth is required, the request body (if any), and a runnable curl example you can paste directly into a terminal — just swap in your own key. Response bodies shown are real, trimmed examples, not abstract schemas.

Authentication

Two kinds of bearer token both work on Authorization: Bearer <token>:

TokenLooks likeUse for
Session tokeneyJhbGciOi... (JWT)The browser, issued after OAuth sign-in. Expires after 30 days.
API keymflint_<random>Scripts, CI, server-to-server. Doesn't expire; revoke it any time from the panel.

Both are resolved to the same account and the same plan/quota — there's no separate "API plan".

Errors

StatusMeaning
400Bad request — invalid manifest, plan, or cloud
401Missing or invalid bearer token
404No such resource (e.g. API key id)
429Rate limit or monthly quota exceeded
501Billing not configured on this server yet

Errors are returned as a plain text body describing what went wrong.

Lint + estimate a manifest

POST/v1/lintauth optional

Body is either raw YAML, or JSON with the manifest inline:

FieldTypeDefaultNotes
manifeststring—required (JSON form only — raw form is the whole body)
cloudstringawsaws, gcp, or azure
saveboolfalsepersist the report — requires auth
 
curl https://cubzi.cloud/v1/lint \
  -H "Authorization: Bearer mflint_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "manifest": "apiVersion: apps/v1\nkind: Deployment\n...",
    "cloud": "aws",
    "save": true
  }'

Check your usage

GET/v1/usageauth required
curl https://cubzi.cloud/v1/usage -H "Authorization: Bearer mflint_xxxxxxxx"
{ "plan": "free", "limit": 50, "used": 12, "remaining": 38 }

limit: 0 and remaining: -1 mean unlimited (Pro).

Check your plan

GET/v1/billing/planauth required
curl https://cubzi.cloud/v1/billing/plan -H "Authorization: Bearer mflint_xxxxxxxx"
{ "plan": "free", "status": "active", "provider": "none" }

Upgrade your plan

POST/v1/billing/checkoutauth required
curl https://cubzi.cloud/v1/billing/checkout \
  -H "Authorization: Bearer mflint_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"plan": "team"}'
{ "url": "https://nowpayments.io/payment/...", "orderId": "mflint_..." }

Open url to pay with crypto via NOWPayments. Your plan updates automatically once the payment confirms.

Manage API keys

GET/v1/api-keysauth required
[{ "id": 3, "label": "ci", "createdAt": "2026-08-01T12:00:00Z", "lastUsedAt": "2026-08-20T09:14:00Z" }]
POST/v1/api-keysauth required

Body: {"label": "ci"} (label is optional). The raw key is only ever in this one response — store it now.

{ "id": 4, "label": "ci", "createdAt": "2026-08-24T10:00:00Z", "key": "mflint_ab12cd34..." }
DELETE/v1/api-keys/{id}auth required

Revokes a key immediately. Returns 204.

CLI & GitHub Action

Prefer not to call the API directly? The CLI wraps it locally and needs no key at all:

mflint ./manifests --format=table --cloud=aws

And the GitHub Action (action/action.yml in the repo) wraps the CLI to comment the report on your PRs — see the repo README for setup.
