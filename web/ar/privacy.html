سياسة الخصوصية

سارية اعتباراً من ٢٦ أغسطس ٢٠٢٦

توضّح هذه السياسة البيانات التي تجمعها Cubzi ("نحن") عند استخدامك لموقع cubzi.cloud، أو CLI الخاص بـ Cubzi، أو GitHub Action الخاص بـ Cubzi (يُشار إليها معاً بـ"الخدمة")، وما نفعله بها.

١. ما الذي نجمعه

معلومات الحساب

عند تسجيل الدخول عبر Google أو GitHub، نستلم بريدك الإلكتروني ومعرّف حساب صادر من ذلك المزوّد. لا نرى أو نخزّن كلمة مرور أبداً — لا يوجد في Cubzi تسجيل دخول بكلمة مرور إطلاقاً.

محتوى الـ manifest

يُعالَج ملف YAML الذي ترسله للفحص لإنتاج تقريرك ولا يُخزَّن إلا إذا فعّلت خيار "الحفظ" صراحةً (أو مررت save: true عبر الـ API) أثناء تسجيل الدخول — وفي هذه الحالة يُحفظ التقرير (المخالفات + تقدير التكلفة) في حسابك لتراجعه لاحقاً. يُجزَّأ محتوى الملف (hash) لمنع التكرار؛ لا يُحتفظ بملف الـ YAML الخام بعد إنتاج ذلك التقرير.

مفاتيح API

إذا أنشأت مفتاح API من اللوحة، نخزّن فقط بصمة SHA-256 الخاصة به، لا المفتاح الخام أبداً. يُعرض المفتاح الخام لك مرة واحدة فقط، عند الإنشاء.

بيانات الاستخدام

نسجّل عدد الفحوصات التي شغّلها حسابك هذا الشهر، لتطبيق حد خطتك. الطلبات المجهولة (غير المسجّلة) تُتبَّع فقط عبر عنوان IP، لفترة وجيزة، لتطبيق حد معدل الطلبات — وهذا غير مرتبط بأي حساب.

معلومات الدفع

تُفوتَر الخطط المدفوعة عبر معالج دفع رقمي خارجي (CoinGate أو NOWPayments). لا نستلم أو نخزّن أبداً تفاصيل دفعك، أو عنوان محفظتك، أو بيانات اعتماد المعاملة — يتولى المعالج الدفع مباشرة ويُخبرنا فقط ما إذا تم دفع الطلب، ونستخدم ذلك لتفعيل خطتك.

٢. كيف نستخدمها

  • لتقديم خدمة الفحص وتقدير التكلفة وعرض نتائجك.
  • لتطبيق حد الفحوصات الشهري لخطتك.
  • للسماح لك بتسجيل الدخول مجدداً ورؤية التقارير المحفوظة ومفاتيح API.
  • لتفعيل أو تجديد خطة مدفوعة بعد تأكيد الدفع.

لا نبيع بياناتك، ولا نستخدم محتوى ملفاتك لأي غرض سوى إنتاج تقريرك الخاص.

٤. الاحتفاظ بالبيانات

تُحفَظ بيانات الحساب والتقارير المحفوظة حتى تحذفها أنت أو تطلب منا حذف حسابك. الفحوصات غير المحفوظة لا يُحتفظ بها إطلاقاً بعد إنتاج التقرير المعروض لك. يمكن إلغاء مفاتيح API في أي وقت من اللوحة، ما يحذف البصمة المخزّنة فوراً.

٥. حقوقك

يمكنك إلغاء مفاتيح API وحذف التقارير المحفوظة بنفسك من اللوحة في أي وقت. لطلب نسخة من بياناتك أو حذف كامل لحسابك، تواصل معنا (انظر أدناه) — سنتصرف خلال وقت معقول.

٦. الأمان

تُقدَّم الخدمة بالكامل عبر HTTPS. تُخزَّن مفاتيح API كبصمات SHA-256، لا كنص صريح. تنتهي صلاحية رموز الجلسة بعد ٣٠ يوماً. لا يوجد نظام آمن تماماً، لكننا لا نخزّن أي شيء لا نحتاجه لتشغيل الخدمة.

٧. ملفات تعريف الارتباط والتتبع

لا تستخدم Cubzi حالياً ملفات تعريف الارتباط (cookies) للتتبع أو أي تحليلات من طرف ثالث. يُخزَّن رمز جلستك في وحدة التخزين المحلية للمتصفح، لا في ملف تعريف ارتباط. إذا تغيّر هذا، ستُحدَّث هذه السياسة أولاً.

٨. خصوصية الأطفال

الخدمة موجّهة للاستخدام المهني/التطويري وليست موجّهة للأطفال دون سن ١٦ عاماً. لا نجمع بيانات عن أي شخص في تلك الفئة العمرية عن علم.

٩. التغييرات على هذه السياسة

إذا تغيّرت هذه السياسة بشكل جوهري، سيُحدَّث تاريخ "السريان" أعلاه. استمرار استخدام الخدمة بعد أي تغيير يعني قبولك للسياسة المحدَّثة.
