The gap between a linter and a cost calculator

Policy linters like kube-linter and Polaris ignore cost. Cost tools like Infracost parse Terraform, not raw manifests. mflint combines both, pre-deploy, on the actual YAML you're about to apply.

A sample of what it catches

Four CRITICAL checks, six WARNING checks, three INFO checks — every rule ships with the exact fix.

  • CRIT Container may run as root
  • CRIT Privileged container
  • CRIT Secret hardcoded in an env var
  • CRIT hostNetwork / hostPID / hostIPC enabled
  • WARN Missing cpu/memory requests or limits
  • WARN Missing liveness/readiness probes
  • WARN No PodDisruptionBudget for multi-replica workloads
  • WARN Image tag not pinned (latest)
  • WARN No NetworkPolicy in the namespace
  • WARN Deployment has no explicit replica count

How it works

No agent to install on your cluster. Input is a YAML file, output is a report.

Paste or point at a manifest

Use the web tool, or run the CLI against a file or a whole directory.

Get a report

Every violation with its severity, the resource it's on, and how to fix it — plus a monthly cost range.

Gate your pipeline

The CLI exits non-zero on any CRITICAL finding; the GitHub Action comments the report on the PR.

Drop it into CI

The GitHub Action builds and runs the CLI, then posts (and updates) one PR comment with the full report.

- uses: <owner>/<repo>/action@main
  with:
    path: ./manifests
    cloud: aws
